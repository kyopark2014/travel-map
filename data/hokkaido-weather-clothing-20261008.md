| 🥈 | **도야 호수 (洞爺湖) 유람선(遊覧船)** · 10/10 | 9~11℃ | 방풍재킷 + 목도리, 실내 선실 활용 |
| 🥉 | **죠잔케이(定山渓) 저녁** · 10/9 | 6~7℃ | 실내 이동 최소화, 온천 활용 |

## 7. 복장 가이드 — 레이어링 전략

│ 👕 1층 (Base) — 흡습·속건            │
│   긴팔 티셔츠 / 얇은 이너              │

└─────────────────────────────────────┘

### ✅ 권장 아이템 매트릭스

| 품목 | 권장 | 우선도 | 이유 |
|---|---|---|---|
| 🧥 **경량 바람막이(방풍)** | 발수 기능 있는 것 | ⭐⭐⭐⭐⭐ | 홋카이도 10월의 **최강 무기** |
| 🧶 **얇은 니트/후디** | 2장 | ⭐⭐⭐⭐⭐ | 레이어링 핵심, 실내 조절 |
| 🧥 **경량 패딩(다운)** | 압축 가능한 것 | ⭐⭐⭐⭐ | 사이로 전망대 (サイロ展望台)·유람선용 |
| 👖 **긴바지** | 면·기능성 | ⭐⭐⭐⭐⭐ | 반바지 절대 불가 |
| 🧣 **목도리/스카프** | 얇은 것 | ⭐⭐⭐⭐ | **체감온도 3℃ 상승 효과** |
| 🧤 **얇은 장갑** | 터치스크린 대응 | ⭐⭐⭐ | 전망대 촬영 시 |
| 🧢 **모자** | 비니 또는 후드 | ⭐⭐⭐ | 두피 보온, 강풍 대비 |
| 👟 **편한 운동화** | 방수 처리 | ⭐⭐⭐⭐⭐ | 지옥계곡·전망대 노면 |
| 🧦 **양말** | 두꺼운 것 여분 | ⭐⭐⭐⭐ | 발 시림 방지 + 젖음 대비 |
| ☂️ **접이식 우산** | 소형 | ⭐⭐⭐ | 강수확률 31~38% |

### ❌ 가져가지 말 것

| 품목 | 이유 |
|---|---|
| ❌ 두꺼운 롱코트 | 버스 이동 많아 거추장스러움, 실내 난방 강함 |
| ❌ 반바지·샌들 | 10월 홋카이도(北海道)에 부적합 |
| ❌ 두꺼운 겨울 패딩 | 아직 이름 (11월부터) |
| ❌ 새 구두·굽 있는 신발 | 도보 관광 많음 |
| ❌ 아끼는 옷 | 노보리베츠 지옥계곡 (登別地獄谷) 유황(硫黄) 냄새 배임 |

### 💡 온천 관련 (죠잔케이/定山渓 · 노보리베츠/登別)

| 항목 | 안내 |
|---|---|
| 수건·유카타(浴衣) | **호텔 제공** — 안 가져가도 됨 |
| 실내 이동 | 유카타(浴衣) + 하오리(羽織) 착용 가능 |
| 온천 후 야외 | ⚠️ **온천 직후 밖에 나가면 급격히 체온 하락** → 30분 쉬고 이동 |
| 개인 세면도구 | 기본 어메니티 제공되나 취향 것 지참 권장 |
| 안경 | 노천탕(露天風呂) 김서림 → 렌즈 착용자는 안경 여분 |
